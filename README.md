# Взял-сделал — сайт сервиса аренды инструмента

Тёмный технологичный лендинг + каталог + корзина. Чистый HTML/CSS/JS, без сборки.

## Что сделано
- **index.html** — лендинг: hero «Инструмент за 2 часа. Без залога», 3 шага как работает, 6 преимуществ (доставка, без залога, видеоинструкции, ТО, поддержка 24/7, эко), популярные инструменты, блок сравнения «купить за 15 990 ₽ vs арендовать за 590 ₽», отзывы, FAQ, CTA.
- **catalog.html** — каталог 16 инструментов с поиском, фильтрами по категориям, цене, наличию, сортировкой (популярные / дешевле / экономия).
- **tool.html?id=...** — карточка инструмента: характеристики, тарифы (сутки/3 дня/неделя/месяц), калькулятор срока и экономии, кнопка «В корзину».
- **order.html** — корзина в localStorage, изменение срока (+/-), адрес, дата, телефон, способ верификации (Госуслуги / паспорт), итог с экономией, модалка успеха.
- **Дизайн**: dark tech — фон #0B0D10, карточки #1C212C, акцент оранжевый #FF6B2B, скругления 20px, Inter + JetBrains Mono, glass-эффект в шапке.

## Данные
`js/data.js` — массив TOOLS (16 позиций): перфоратор Bosch, дрель Makita, болгарка DeWalt, газонокосилка Husqvarna, Karcher K5, сварка Ресанта, тепловизор Flir, лазерный уровень, бетономешалка и т.д. Поля: цена за сутки/3 дня/неделю/месяц, цена покупки, иконка, specs, popular.

Логика цен: 
- 1 день = priceDay
- 2-3 дня = пропорционально price3
- 4-7 дней = priceWeek
- 8-30 дней = priceMonth

Экономия считается как buyPrice - rent.

## Запуск
Просто открой `index.html` или запусти локальный сервер:
```bash
python3 -m http.server 8000
```
